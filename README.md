# BoxChat

A simple chat application built while learning Node.js, Express.js, MongoDB, Mongoose and EJS.

## Features

- Create chat messages
- View all chats
- Edit messages
- Delete messages
- MongoDB database integration
- Server-side rendering with EJS

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML
- CSS

## Note

This project started as a tutorial-based learning project. I customized the project with my own branding, styling and sample chat data while learning backend development.
